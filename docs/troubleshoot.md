# 排查手册（出问题怎么解决）

> 左边是**症状**，右边是**怎么解决** ✓ —— 每一条都是我们实机踩过的 ✓
> 模型替换（武器 / 物品）通用 ✓；游戏专属的细节见 `docs/guides/` ✓

## 一、mod 没生效

| 症状 | 怎么解决 |
|---|---|
| 日志里**没有** `[名字] 规则 N 条` 这一行 | **四处名字必须完全一致**：`info.ini` 的 `name` · 目录名 · csproj 的 `AssemblyName` · 命名空间 + 类名 `ModBehaviour`。不一致的症状是**静默不加载**，游戏不报错 ✗ |
| 有 `规则 N 条`，但东西没变 | ① **匹配条件写错**了（`typeIDs` 抄错一位就"什么都没命中"✗）；② 看那条规则的 `world=` / `handheld=` 是不是"关" ✗ |
| 改了 `config.json` 没反应 | 存盘**即生效**（0.25 秒内热重载 ✓）—— 但**第一次进游戏**要让那件东西**重新生成一次** ✓（见下面第二节第一行）|
| 换了图标没变化 | **图标要重启游戏** ✓（热重载只重挂模型 ✓ 不重设图标 ✓）|

## 二、"看到的东西不对"

| 症状 | 怎么解决 |
|---|---|
| 模型**没出现**，看到的还是原来的东西 | **让它重新生成一次**：丢地上再捡起来 ✓ / 换下来再穿上 ✓ / 重进关卡 ✓（游戏的实体有缓存 ✓ 不是没生效 ✗）|
| 物品**退回一张 2D 图标** ✗ | 我们那份图形模板**被销毁**了 ✓ → **重启游戏**先恢复 ✓；如果每次都这样，看 `模板被销毁` 那条（见 `ItemModel.cs` 里模板的生命周期注释 ✓）|
| 物品**整个消失** ✗ | 关掉旧外观了、我们的却没显示 ✗ → ① **层**别动（游戏掉落物就是 `0` 层 ✓ 我们自己改层会发白/看不见 ✗）② 模板别放进物品的子树 ✓ ③ 模型文件是不是坏的 → 用 `model-check` 看 ✓ |
| 模型**发白 + 渲染在最前面** ✗ | 用错**层**了 ✓ → **层一律不动** ✓（别照搬"穿戴"那条路的 `Character` ✓ 掉落/展示那条用的是 `0` ✓）|
| 模型**颜色脏 / 有发光斑** ✗ | 克隆游戏材质时**没清其它贴图槽** ✗ → 用 `GameApi.ApplyOurTexture` ✓（它换基础色 + 关发光 + 清法线/遮蔽等 ✓）|
| 模型**跟着玩家跑** ✗ / **跟着物品掉地上** ✗ | 图形被挂成了**物品的子物体** ✗ → 图形要**独立**（`SetParent(null)` ✓ 挪到世界外 ✓）|
| **载入画面**里看到游离的模型 ✗ | 图形 / 手持 agent 的**模板没挪到世界外** ✗ → 挪到 `y = -5000` ✓（副本会被游戏自己摆正 ✓）|
| **越玩越卡，最后卡死** ✗ | ① 注册"动态条目"之后**要跳过自己造的克隆** ✓（否则克隆→又被扫到→再克隆 ✗）② 同一 `typeID` **只注册一次** ✓ ③ 别**每帧扫全场景物品** ✗（节流 ✓）|
| 挂点**挑错**（挂到灯 / 特效上 ✗） | 用**游戏自己声明的渲染器集合**找本体 ✓：`CharacterSubVisuals.renderers` ✓（运行时挂的灯/特效**不在这个集合里** ✗）—— 武器再按名字含 `WPN_` 优先 ✓ |
| 模型**巨大 / 极小** ✗ | Tripo 出来的模型**最长边被归一化成 ≈1 m** ✓；游戏那一档是：背包 ≈0.55 · 防弹衣 ≈0.80 · 头盔 ≈0.65 · 面具 ≈0.65 · 耳机 ≈0.78 ✓ → 按游戏那一档做 ✓ |
| 模型**穿模 / 悬空** ✗ | 尺寸不合适（比如拿 1 m 的枪去当耳机 ✓）→ 换个比例合理的模型 ✓ |
| **朝向反了** ✗ | Tripo 出的靠**提示词**保证朝向 ✓；自带模型配 `config.json` 的 `front` ✓ |

## 三、看着像问题、其实不是

| 现象 | 说明 |
|---|---|
| **UI / 背包格子里的图标没变** ✓ | **正常** ✓ —— 本能力只换**世界里的模型** ✓ 图标属另一条能力 ✓ |
| 拿在手里 / 使用时**还是那张 2D 图** ✓ | 有的物品**没有"拿在手里"这个表示** ✓（它"使用时"那张图是 **UI 画的** ✓）→ 本能力够不着 ✓ 属图标能力 ✓ |
| 只有**改了的那几件**变了 ✓ | 正常 ✓ —— 规则是**按 `typeIDs` / `targets` 精确匹配**的 ✓ 不会波及其它 ✓ |

## 四、日志里能对照的三种行

| 日志 | 意思 |
|---|---|
| `[名字] 规则 N 条：…` | mod 加载了 ✓ 配置读到了 ✓（没有这行 = 没加载 ✗ 见第一节）|
| `已换：'X'(typeID=N)｜关旧外观 n 个｜挂到 '锚点名'｜…` | 换成功 ✓ **挂到的那个名字**最能说明"挂点挑对没" ✓ |
| `跳过：'X' <原因>` | 没换 ✓ 原因写在后面 ✓（模型不可用 / 没有 ItemGraphic 之类 ✓）|
