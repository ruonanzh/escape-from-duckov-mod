# Cookbook（做法速查）

## 1. 克隆游戏里的 prefab，当"新物体自己的 prefab"

（出处 ✓：物品没有 `itemGraphic` 时，我们克隆它自己的物品 prefab 来当新的 prefab ✓）

- 克隆出来的那份 **要放在很远的地方** ✓ —— `transform.position = (0, -5000, 0)` ✓
  它是**模板** ✓ 不该在世界里露出来 ✓；游戏**实例化副本**时会自己摆正
  （把副本 `SetParent` 到显示点 ✓ 再把位置/旋转/缩放归零 ✓）
- 并 **`DontDestroyOnLoad`** ✓ —— 否则**换场景时被销毁** ✗
  → 游戏手上的 `itemGraphic` 变成"已销毁引用" ✗ → **退回 2D 图标** ✓
- ⚠️ 但**别把它挂成物品的子物体** ✗ —— 那样模型会**跟着那件物品渲染** ✓
  （"一把枪跟着玩家跑" / "跟着物品掉地上" ✓）→ 独立放置 ✓（`SetParent(null)` ✓）

## 2. 一个"外观"是三层

| | 是什么 | 谁决定 |
|---|---|---|
| ① **世界模型** | 地上 / 展示 / **穿戴**的样子 | config `world`（**默认开** ✓）—— 纯外观 ✓ 不改行为 ✓ |
| ② **拿在手里** | 手里 / 装备的样子 | config `handheld`（**默认关** ✓）—— ⚠️ 会**改行为**（变成可拿 + UI 可选中 ✓）|
| ③ **2D 图标** | 背包格子 / "使用时"那张图 | **游戏自带** ✓ **我们从不删** ✓ 但**可以替换** ✓ |

- 第 ③ 层那张图是 **UI 画的**（`Duckov.UI.UsageUtilitiesDisplay`）→ "3D 模型"这条路**够不着** ✓
  （要变它只能**换图标** ✓ 那是另一条能力 ✓）
- 物品**自己没有 3D 图形**时（糖果那类 ✓）→ 我们**给它造一份图形** ✓ = 换掉第 ③ 层显示的东西 ✓

## 3. 怎么找到"该换的那个 mesh"

1. **游戏自己声明的集合** ✓：图形根上的 `CharacterSubVisuals.renderers` ✓ = "这套外观用哪些渲染器" ✓
   → 运行时挂上去的**灯 / 特效不在里面** ✓（实测：头盔被 `SodaPointLight` 骗走过 ✗）
2. 只认 `MeshRenderer` / `SkinnedMeshRenderer` ✓（Sprite / 灯 / 粒子一律排除 ✗）
3. **武器**再加一条 ✓：排除 `ShowIf_*` / `HideIf_*` ✓，并优先名字**含** `WPN_`
   （**子串** ✓ 不是前缀 ✗ —— 很多枪叫 `Pfb_WPN_TOZ66_S_1` ✓）
4. 还有多个 → 取**包围盒最大**的 ✓
5. 集合为空 / 没有那个组件 → 才回退到"遍历 + 排灯/特效 + 比大小" ✓
- ⚠️ **层一律不动** ✓ —— 游戏掉落物的图形就是 `0` 层 ✓ 自己改层会**发白 / 看不见** ✓

## 4. 层（layer）—— **一律不动**

| 层 | 号 | 谁在用 |
|---|---|---|
| **Default** | 0 | 游戏**世界里**的掉落 / 展示物品 ✓（实测：掉落物 prefab 就是 0 层 ✓ 而且看得见 ✓）→ **我们也保持 0** ✓ |
| **Character** | 9 | 游戏给"**穿在身上 / 拿在手里**"的视觉 ✓（`CharacterSubVisuals.showLayer` ✓）|
| **SpecialCamera** | 31 | 游戏用来"**隐藏**"的层 ✓（`hiddenLayer` ✓ —— 只有特写相机看得见 ✓ = 常规视角下等于隐身 ✓）|
| **SodaLight** | — | 游戏自定义：**灯效** ✓ |
| **UI** | 5（Unity 内置）| 界面用 ✓ —— ⚠️ 物品的 GameObject 平时就是给 UI 用的 ✓ 拿它当世界模型的层会**发白 + 渲染在最前** ✗ |

- 游戏用**层**来开关视觉 ✓（不是 `SetActive` ✗）：显示 → `Character` ✓ · 隐藏 → `SpecialCamera` ✓
- ⇒ **两条路不一样** ✗：**掉落 / 展示 = `0` 层** ✓ · **穿在身上 / 拿在手里 = `Character`** ✓
- ⇒ 所以我们**自己不挑层** ✗：就保持 **`0`** ✓；走"就地改"时我们的 mesh 会**继承锚点的层** ✓（游戏已经设好的 ✓）
