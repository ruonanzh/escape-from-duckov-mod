# ItemModelSwap —— 替换**物品**模型（示例 mod）

把**一件（或一批）物品**在世界里的模型换成你给的 GLB。
（背包 / 头盔 / 弹匣 / 任何 `Item` 都行 ✓ —— 物品**没有**武器那些挂点，所以不用 `slots` ✓）

## 只做一件事 ✓

```
① 放模型文件进这个目录（例：item.glb）
② 改 config.json：target（或 typeIDs）指到那件物品
③ 装机、进游戏：那件物品的模型就是你的了 ✓
```

```json
{ "typeIDs": [36], "model": "backpack.glb" }
```

## config.json 字段（一条规则一份 ✓）

| 字段 | 说明 |
|---|---|
| `targets` | 物品**对象名全等**（数组 ✓ 不区分大小写；例 `["Item_BackpackLV3"]` ✓ 写错一个字符就不命中 ✗）|
| `typeIDs` | 或精确命中（数组 ✓ 例 `[260]`）—— **更稳 ✓**（对象名是英文的，不受本地化影响 ✓）|
| `model` | 放在本 mod 目录里的 GLB（相对名或绝对路径 ✓）|
| `front` | 仅**自带模型**需要：`auto`/`+z`/`-z`/`+x`/`-x` 声明朝向（Tripo 出的靠提示词保证 ✓）|

**要换多件物品？** 用 `entries`（一个 mod 多条规则 ✓ 按数组顺序匹配，**先命中的生效** ✓）：

```json
{ "entries": [
    { "typeIDs": [260], "model": "backpack.glb" },
    { "targets": ["Item_BackpackLV3"], "model": "backpack_lv3.glb" } ] }
```

> ⚠️ 给了 `entries` 就**只看 entries**（扁平字段被忽略）；两者不要混用。

## 运行时会做（缺哪件都会"只换一半" ✗）

```
① 克隆那件物品自己的图形 prefab（保留挂点 / groundPoint / 各种设置 ✓）→ 只换几何 → 写回 item.ItemGraphic
② 写到**物品模板**（ItemAssetsCollection.GetPrefab ✓）→ 以后每个实例开局就是对的了 ✓
③ 清实体缓存（ClearAgentCache ✓）→ 游戏下次建实体时读我们的图形 ✓
④ 就地换**已经拿在手里**的那个（只影响以后生成的实例，手里那个不会自己变 ✗）
```

## 两个别搞混的地方 ✓

- **模型 ≠ 图标**：这里只换世界里的**模型** ✓；背包卡片上的**图标**不变 ✗（图标另做 ✓ 见 replace-item-icon）
- **模型尺度 = 真实米制** ✓：物品没有武器那样的"对齐/槽位"步骤 ✓ → 模型多大就多大 ✓
  （Tripo 出的模型最长边默认 ≈ 1 m ✓ → **偏大**的记得让它按真实尺寸做 ✓，或换一个更小的物体去试）

## 改完不用重启 ✓

`config.json` **存盘即生效**（热重载 ✓ 0.25 秒内 ✓）；但**第一次进游戏**要让物品重新实例化一次
（丢地上再捡起来 / 重进关卡 ✓）才会看到新模型 —— 这是游戏自己缓存实体导致的 ✓。

## 验收

- 日志：`[ItemModel] 已换：'Item_Backpack_Lv_3'(typeID=260) ← item.glb｜锚点='…'｜关旧零件 N 个…`
- 游戏里：那件物品（地上/手里/仓库里 ✓）变成你的模型 ✓
